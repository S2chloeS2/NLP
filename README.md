# Natural Language Processing — Columbia CS

Coursework for Columbia's NLP course (COMS 4705), from n-gram language models through
retrieval-augmented generation.

| | Assignment | Built |
|---|---|---|
| **HW1** | Trigram language model | `trigram_model.py` — n-gram counts, perplexity, text classification |
| **HW2** | Neural network dependency parser | Transition-based parser with a feed-forward network |
| **HW3** | Image caption generation | LSTM caption generator on Flickr data (notebook) |
| **HW4** | Retrieval-augmented generation | RAG pipeline |

The arc of the course is visible in the order: count-based statistics → learned
representations → sequence models → retrieval over a corpus.

## Running

Assignments are Python; HW3 is a Jupyter notebook.

```bash
cd HW1 && python trigram_model.py
```
